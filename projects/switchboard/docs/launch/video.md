# the 60 s video

screen only (unless you decide to show your face 5 s at the start). no voice-over. captions burned in, lowercase. Ghostty, dark theme, big font (18-20 pt), window ~1600×1000.

prep: a demo repo with a real mobile signup page, a sad 404 and a csv export (open: Gabriel picks a toy repo like 'acme' from the landing demos, or a real one). a fresh bise thread. do 2-3 takes, keep the calmest.

| time | on screen | caption |
|---|---|---|
| 0-5 s | `cd ~/app && bise`. the gloss appears | `bise /beez/ · a quick kiss on the cheek :*` |
| 5-25 s | three messages typed back to back, no waiting: "signup is slow on mobile", "the 404 page is so sad", "the csv export crashes on emoji 😭". three agents start in the panel | `you talk. i run the agents.` |
| 25-40 s | ⌥2 into one agent, one line, ⌥0 back. main answers a question in the thread by itself | `talk to any agent. or don't.` |
| 40-55 s | ✓ lines arrive. one card in the inbox, answered with one key | `only the real decisions reach you.` |
| 55-60 s | black, `bise.dev` + install line | `one thread per repo. you stay in flow.` |

rules: don't speed up the model output without saying so (a small "2×" in a corner is enough). no fake results: only what happened in the take.

fallback if no take works by 13:00: a screen capture of the landing's "this is what flow looks like" demo + the hero, 30 s, same captions (ask designer).

X export: mp4, H.264, 1920×1080 or 1280×720, < 512 MB. first frame = the gloss (it's the thumbnail).
